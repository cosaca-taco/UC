## 1. ご相談の趣旨

恵那市では、医療機関の無い地域でも安心して医療を受けられる体制をつくるため、**移動診療車による医療MaaS**を中心とした実証事業を計画しています。財源には国の**地域未来交付金（令和9年度当初分）**の活用を予定しています。

本事業では、**市立恵那病院（指定管理者：貴協会）を住民に最も近い「フロントエンド」**とし、専門医療の「バックエンド」となる藤田医科大学とオンラインで結ぶ構想です。総合診療を軸に全国で地域医療を展開されている貴協会に中核的な役割をお願いしたく、事業の方向性についてご相談申し上げます。

## 2. 背景

- 串原・山岡・飯地・笠置など**医療機関の無い地域**で、人口減少と高齢化が進んでいます。
- 免許返納や公共交通の縮小により、**通院そのものが難しい高齢者**が増えています。
- 地域では常勤の専門医がいない診療科があり、遠方の病院への通院や転院が住民の負担になっています。
- 市は「恵那市地域医療ビジョン」（令和6年3月）と「恵那モデル実施計画（案）」（令和7年5月）で、**移動診療車（D to P with N）とオンライン診療の導入検討**を位置づけています。本事業はその具体化です。
- 貴協会には国保山岡診療所でのオンライン診療の取組などで、すでに大きなご協力をいただいています。

## 4. 検討プロジェクト（協会と大学の現場同士の連携）【新設】

本事業を実際に動かすのは、市立恵那病院と藤田医科大学の**現場の医師・看護師・連携担当者**です。組織間の協定や交付金の手続きだけでは決まらない「誰に・いつ・どう相談するか」「どんな情報を・どの形で渡すか」を現場同士で話し合い、顔の見える関係をつくるため、**「（仮称）恵那・藤田 医療連携検討プロジェクト」**を設けたいと考えています。

| 項目 | 内容（案） |
|---|---|
| 目的 | 恵那病院（地域医療振興協会）と藤田医科大学の**現場同士の意思疎通**を図る |
| 位置づけ | 事業全体を決める「（仮称）恵那市医療MaaS推進協議会」の下に置く、現場の作業部会 |
| メンバー | 恵那病院：総合診療医、同乗看護師、地域医療連携室、医事・情報システム担当<br>藤田医科大学：対象診療科の医師、地域連携・遠隔医療の担当部門、事務担当<br>恵那市：地域医療課（事務局）、デジタル担当<br>※ 地域医療振興協会本部・薬局・システム事業者は必要に応じて参加 |
| 進め方 | キックオフは対面で**相互訪問**（大学の医師にも重点地区・移動診療車のルートを見ていただく）。その後は**月1回のオンライン定例会**と、テーマ別のワーキンググループ |
| ワーキンググループ | 診療科・対象患者／運用（相談の受付・対応時間・緊急時）／情報・システム（共有する情報・個人情報）／教育（合同症例検討会・研修） |
| 成果物 | 連携運用マニュアル、対象診療科と対応体制の合意、システム要件、合同研修の記録、課題・改善リスト |
| 時期 | 令和8年度中（1月目途）に立ち上げ、実証期間中も継続 |
| 費用 | 会議・旅費・合同研修・専門医の対応謝金は事業費（交付金）で負担する方向で調整（交付決定前は市の単独予算で対応） |

## 6. 費用と交付金の考え方（案）

- 車両・医療機器・通信機器・オンライン診療システムなどの**初期費用は市が交付金を活用して負担**する想定です。
- 実証に要する**人件費（オンライン診療を担う医師、同乗看護師など）を事業費に計上**し、市から委託する形を想定しています。診療報酬の収入との関係（二重に計上しない整理）は、ご協議のうえ整理します。
- 電子カルテの改修・外部接続にかかる費用は事業費で負担する方向ですが、指定管理者が管理するシステムのため、費用負担と資産の扱いをご相談させてください。
- 令和11年度以降は、**診療報酬と市の予算で継続**できる仕組みを実証の中で検証したいと考えています。
- 指定管理協定との関係（業務範囲・費用の扱い）は、別途整理させていただきます。

## 8. ご検討いただきたい事項

1. 本事業の方向性と、市立恵那病院が「フロントエンド」を担う構想へのご意見
2. オンライン診療を担当いただく医師・同乗いただく看護師の体制（運行日数・時間帯の目安）
3. 人件費・運行費の負担方法（委託、指定管理協定の変更など）と診療報酬の扱い
4. **恵那病院の電子カルテ**の製品・更新時期と、車内から使うための外部接続の可否、協会としてのシステム方針
5. **検討プロジェクトに参加いただく現場担当者**（医師・看護師・連携室など）と、キックオフ（相互訪問）の時期
6. 藤田医科大学との連携で、現場として事前にすり合わせておきたい点
7. 国保山岡診療所でのオンライン診療など、これまでの取組で得られた知見や課題
8. 推進協議会へのご参画（委員のご推薦）
9. 貴協会の他施設での類似の取組（移動診療車・遠隔医療）の事例
