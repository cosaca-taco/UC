# 地域医療の将来像と実証実験企画（国の交付金申請を目指す）

本フォルダは、地域医療の将来像を描き、実証実験の企画案・事業案を作成して国の交付金に申請するまでの検討資料を管理します。

## 検討の進め方（フェーズ）

| フェーズ | 内容 | 成果物 | 状態 |
|---|---|---|---|
| 0. 前提・条件整理 | 申請主体、対象地域、目標、制約、交付金要件を整理 | `01_目標・条件整理シート.md` | **条件確定 v4** |
| 1. 現状分析 | 人口・受療・医療資源・移動・救急等のデータ収集と課題抽出 | `03_現状分析.md`（記入様式） | **様式作成** |
| 2. 将来像・目標設定 | 2035〜2040年の地域医療の姿、実証で検証すべき仮説、KPI | 将来像（ビジョン）1枚 + KPIツリー | 未着手 |
| 3. 企画案 | 実証テーマの比較・選定、実証の設計（対象・期間・体制・手法） | `02_企画案_骨子.md`（骨子 v0.4） | **着手** |

## 進め方の基本方針

1. **交付金の要件から逆算する**：採択されるには「交付金の目的・評価観点」と「地域の課題」の両方に合致する必要がある。
2. **実証で終わらせない**：実証後に診療報酬・自治体予算・事業収入等でどう自走させるか（持続性）を最初から設計する。審査でも重視される。
3. **合意形成を早めに**：医師会・病院・薬局・消防・介護事業者・住民の協力が不可欠。体制づくりを企画と並行して進める。
4. **KPIは測れるもので**：アウトカム（受診機会・移動負担・救急搬送時間・医療者負担など）と、測定方法・ベースラインをセットで決める。
