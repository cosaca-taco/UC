# 02 企画案 骨子（たたき台 v0.1）

作成日：2026-11-11 ／ 前提：`01_目標・条件整理シート.md` の確定条件

> 【要確認】は未確定事項、【要見積】は業者見積が必要な金額です。金額はすべて規模感をつかむための仮置きです。

---

## 1. 事業名（仮）

**恵那市「どこでも専門医療」実証事業**
― 市立恵那病院と藤田医科大学をオンラインで結ぶ医療MaaS・専門医療連携モデル ―

（別案：「恵那つながる医療MaaS」「恵那モデル・オンライン地域医療ネットワーク」）

## 2. 背景と課題（要約）

- 恵那市は中山間地域が広く、特に恵南地域などで人口減少・高齢化が進み、医療機関の患者数減少・救急受入困難・医療人材不足が生じている（市地域医療ビジョン、県の東濃圏域対応方針）。
- 高齢者の免許返納や公共交通の縮小により、**通院そのものが困難な住民**が増えている。
- 地域の医療機関では **専門医が常勤していない診療科** があり、専門的な判断が必要な患者は遠方の病院へ通院・転院せざるを得ない。
- 処方薬の受け取りも通院と同様の移動負担がある。
- 市は「恵那モデル実施計画（案）」で移動診療車（D to P with N）やオンライン診療の導入を検討しており、**本事業はその具体化**に当たる。

【要確認】数値（重点地区の人口・高齢化率、医療機関までの距離・時間、無医地区等）はフェーズ1で整理して追記する。

## 3. 目指す姿（2035〜2040年の将来像）

> **「住んでいる場所にかかわらず、かかりつけの総合診療と、必要なときの専門医療が受けられる恵那市」**

```
  【患者・地域】              【フロントエンド】               【バックエンド】
  重点地区の住民宅・公民館      市立恵那病院（総合診療）          藤田医科大学
       │                    （地域医療振興協会）               （専門医療・先進医療）
       │  ① 医療MaaS                 │                              │
       ├── 移動診療車 ─ 看護師 ──オンライン── 総合診療医 ──オンライン── 専門医
       │  （D to P with N）           │   ② 医師間の遠隔支援（D to D）│
       │                            │      必要時は三者同時          │
       │                            │      （D to P with D）         │
       │  ③ 服薬                     │                              │
       └── オンライン服薬指導 ── 薬局 ── 薬の配送                       │
                                    │                              │
                         国保上矢作病院・公立診療所（Step2以降で接続）
```

- 住民に最も近い入口（フロント）は、総合診療を担う **市立恵那病院**。
- 専門的な判断が必要なときは、恵那病院の医師が **藤田医科大学の専門医** にオンラインで相談・同席を依頼する（バック）。
- 移動・通院・薬の受け取りの負担を、**車両とオンラインで地域側に寄せる**。

## 4. 段階的な展開（ロードマップ）

| 段階 | 時期（案） | 内容 | 交付金での位置づけ |
|---|---|---|---|
| **Step0 準備** | 令和8年度（〜令和9年3月） | 協定締結（市・地域医療振興協会・藤田医科大学・薬剤師会等）、重点地区選定、住民説明、車両・システム仕様決定、交付金申請 | 申請準備 |
| **Step1 医療MaaS実証** | 令和9年度 | 移動診療車による D to P with N を重点地区で開始。オンライン服薬指導＋薬の配送を組み合わせる。必要時に藤田医科大学の専門医が同席する三者診療を試行 | **交付金の中心** |
| **Step2 専門連携の拡大** | 令和10年度 | 恵那病院の外来・入院患者について、藤田医科大学との D to D（遠隔相談、画像等の共有、専門外来のオンライン化）を診療科単位で拡大。上矢作病院・公立診療所を接続 | 複数年度の継続分 |
| **Step3 恵那モデルの確立** | 令和11年度〜 | 恵那病院全体が専門医療機関と常時つながる仕組みとして定着。診療報酬・市予算で自走し、東濃圏域や地域医療振興協会の他施設へ横展開 | 自走・横展開 |

## 5. 実証の内容

### 5-1. テーマ①：医療MaaS（移動診療車によるオンライン診療）

| 項目 | 内容（案） |
|---|---|
| 方式 | **D to P with N**：看護師が同乗した車両が患者宅・公民館等へ行き、車内で恵那病院の医師がオンライン診療 |
| 車両 | オンライン診療用の機器（通信、モニター、バイタル測定機器、心電計・エコー等）を搭載したワゴン車。購入・リース・既存の公用車改造を比較 【要見積】 |
| 運行 | 重点地区を曜日ごとに巡回（例：週2〜3日）。予約制。運転手は委託または市の交通事業と連携 【要確認】 |
| 対象者 | 重点地区に住む慢性疾患で定期受診中の高齢者、通院困難者、退院後のフォローが必要な方 |
| 医師側 | 恵那病院の総合診療医。必要に応じて藤田医科大学の専門医が同時接続（D to P with D） |
| 検証すること | 利用者数・満足度、通院負担の削減、医師の移動時間削減、診療の質（対面と比べた安全性）、運行コスト、診療報酬での採算 |

### 5-2. テーマ②：医師間の遠隔支援（D to D）

| 項目 | 内容（案） |
|---|---|
| 方式 | 恵那病院の医師と藤田医科大学の専門医をオンラインで結び、症例相談・画像の共有・三者診療を行う |
| 対象診療科 | 【要確認】恵那病院で常勤医が不足している診療科を優先（例：循環器・神経・皮膚・精神・小児などから選定） |
| 運用 | 定期の症例カンファレンス（例：週1回）＋随時相談の仕組み。セキュアな映像・画像共有システムを導入 |
| 検証すること | 相談件数、遠方の病院への紹介・転院の回避件数、患者の移動負担削減、恵那病院医師の負担感・教育効果 |

### 5-3. テーマ③：オンライン服薬指導＋薬の配送

| 項目 | 内容（案） |
|---|---|
| 方式 | 移動診療車で処方 → 市内の薬局がオンラインで服薬指導 → 薬を自宅へ届ける |
| 配送手段（比較） | (a) 翌回の移動診療車が届ける、(b) 地域の交通・物流事業者との貨客混載、(c) 薬局による配送、(d) ドローン（中長期） 【要確認】 |
| 検証すること | 処方から受け取りまでの時間、住民の負担削減、薬局の業務負担、配送コスト |

## 6. 推進体制（案）

| 主体 | 役割 |
|---|---|
| **恵那市**（医療福祉部 地域医療課 等） | 申請者・事業統括、関係機関の調整、住民周知、地域公共交通との連携、効果検証の取りまとめ |
| **市立恵那病院／地域医療振興協会** | フロントエンド。総合診療医・看護師の配置、移動診療車の運用、患者の予約・記録管理。協会の全国ネットワークでの知見共有・横展開 |
| **藤田医科大学** | バックエンド。専門医による遠隔支援・三者診療、症例カンファレンス、実証の学術的評価（論文化・エビデンス化）への協力 |
| 恵那医師会 | 地域の診療所との役割分担、患者の紹介・逆紹介 |
| 薬剤師会・市内薬局 | オンライン服薬指導、薬の配送 |
| 国保上矢作病院・公立診療所 | Step2以降で接続 |
| 地域包括支援センター・介護事業者 | 対象者の掘り起こし、在宅療養との連携 |
| 交通事業者・IT事業者 | 車両運行、システム構築・保守（公募で選定） |
| 岐阜県 | 地域医療構想・医療計画との整合、県の基金等との連携 |

**県境を越える連携の留意点**：藤田医科大学は愛知県のため、市・恵那病院・大学の三者協定（役割、費用負担、責任分担、個人情報の取扱い）を Step0 で締結する。

## 7. 予算（規模感の仮置き）

前提：**総事業費 2,000万〜3,000万円を3か年で実施** と仮定（単年度あたりの場合は拡大可能）【要確認】

| 費目 | 令和9年度 | 令和10年度 | 令和11年度 | 備考 |
|---|---:|---:|---:|---|
| 移動診療車（改造・医療機器搭載） | 800〜1,200万 | – | – | リースなら年度分割 【要見積】 |
| オンライン診療・D to D システム（構築・通信） | 300〜500万 | 100〜200万 | 100〜200万 | 既存の市・協会のシステム活用で圧縮 |
| 運行・看護師・運転手（実証期間分） | 300〜500万 | 300〜400万 | 200〜300万 | 診療報酬収入で一部相殺 |
| 薬の配送・服薬指導の運用 | 50〜100万 | 50〜100万 | 50万 | |
| 効果検証・住民周知・協議会運営 | 100〜200万 | 100万 | 100万 | 大学との共同研究と連携 |
| **合計（目安）** | **約1,550〜2,500万** | **約550〜800万** | **約450〜650万** | **3か年 約2,550〜3,950万** |

- 上限側は想定（3,000万）を超えるため、**車両のリース化・既存システムの活用・運行日数の調整** で総額を3,000万以内に収める。
- 交付金の補助率を1/2とすると、市の負担は総額の約半分（1,000〜1,500万）。地方財政措置の有無を確認する。

## 8. 交付金の活用方針（案）

| 候補 | 想定する使い方 | 論点 |
|---|---|---|
| **地域未来交付金 デジタル実装型 TYPE A（利用推進型）** | 令和9年度の初期導入（車両の機器・オンライン診療システム・D to Dシステム） | 補助率1/2・国費上限1億円（令和8年度の例）。**原則として単年度の実装事業**で、他地域で実績のあるモデルの導入が基本 → 医療MaaSは伊那市などの先行例があり適合しやすい 【要確認：令和9年度要件】 |
| **地域未来交付金 第2世代型（ソフト事業）** | 複数年度の運用・専門連携の拡大（Step1〜2） | 複数年度の計画を組める型。地方版総合戦略への位置づけとKPI設定が必要 【要確認】 |
| 地域医療介護総合確保基金（岐阜県） | 遠隔医療設備、在宅医療体制 | 県の計画への提案が必要。交付金との重複不可 |
| 診療報酬・市単独予算 | 実証後の運用費 | 自走のための財源 |

→ **基本戦略：初年度の導入を「デジタル実装型 TYPE A」、2年目以降の運用・拡大を「第2世代型」またはそれに相当する型で申請し、令和11年度以降は診療報酬と市予算で自走する**（型の併用・重複の可否は内閣府・県に要確認）。

## 9. KPI（案）

| 区分 | 指標 | 目標の考え方（数値は現状把握後に設定） |
|---|---|---|
| アウトプット | 移動診療車の運行日数・訪問件数 | 例：年間〇日・延べ〇件 |
| アウトカム（住民） | 利用者の通院にかかる時間・費用の削減 | 1人あたり〇分／〇円削減 |
| アウトカム（住民） | 利用者満足度・継続利用意向 | 80%以上 |
| アウトカム（医療） | 藤田医科大学との D to D 件数、遠方の病院への受診・転院の回避件数 | 年間〇件 |
| アウトカム（医療） | 医師の移動時間の削減（往診比較） | 〇時間／月 |
| アウトカム（服薬） | 処方から薬を受け取るまでの日数 | 〇日以内 |
| 持続性 | 実証後の継続運行、診療報酬で賄える運営費の割合、他地区・他施設への横展開数 | 令和11年度に自走 |

## 10. 主なリスクと対応

| リスク | 対応 |
|---|---|
| 高齢者がオンライン診療に不安を感じる | 看護師同乗方式（D to P with N）、地域包括・民生委員と連携した説明会 |
| 医師・看護師の人員確保 | 地域医療振興協会のネットワーク、藤田医科大学の支援、運行日の集約 |
| 運営費が実証後に賄えない | 実証中に診療報酬での採算を検証し、運行ルート・頻度を最適化 |
| 法令・指針への適合（オンライン診療指針、改正医療法、個人情報、医療情報システムの安全管理） | 企画段階で厚労省指針に沿った運用手順書を作成、県の医療担当課へ事前相談 |
| 県境を越える連携の調整 | 三者協定、費用負担の明確化 |
| 交付金の要件・スケジュールの変更 | 内閣府・県への早期の事前相談、複数の財源候補を並行確保 |
