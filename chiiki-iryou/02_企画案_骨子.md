## 1. 事業名（仮）

**恵那市「どこでも専門医療」実証事業**
― 市立恵那病院と藤田医科大学をオンラインで結ぶ医療MaaS・専門医療連携モデル ―

（別案：「恵那つながる医療MaaS」「恵那モデル・オンライン地域医療ネットワーク」）

## 2. 背景と課題（要約）

- 恵那市は中山間地域が広く、特に恵南地域などで人口減少・高齢化が進み、医療機関の患者数減少・救急受入困難・医療人材不足が生じている（市地域医療ビジョン、県の東濃圏域対応方針）。
- 高齢者の免許返納や公共交通の縮小により、**通院そのものが困難な住民**が増えている。
- 地域の医療機関では **専門医が常勤していない診療科** があり、専門的な判断が必要な患者は遠方の病院へ通院・転院せざるを得ない。
- 処方薬の受け取りも通院と同様の移動負担がある。
- 市は「恵那モデル実施計画（案）」で移動診療車（D to P with N）やオンライン診療の導入を検討しており、**本事業はその具体化**に当たる。

**重点地区（確定）：医療機関の無い地域 ― 串原・山岡・飯地・笠置 など**

| 地区 | 位置 | 想定する特徴（要データ確認） |
|---|---|---|
| 飯地 | 市北部 | 山間部の小規模集落。市中心部（恵那病院）へは比較的近いが公共交通が限られる |
| 笠置 | 市北部 | 同上 |
| 山岡 | 恵南地域 | 国保山岡診療所の情報あり → 診療日・時間の確認が必要。恵那病院から距離がある |
| 串原 | 恵南地域（市南東端） | 市内で最も遠方の地区の一つ。高齢化・人口減少が進む |

数値（人口・高齢化率・恵那病院までの距離と所要時間・公共交通・通院先）は `03_現状分析.md` で整理して追記する。

## 3. 目指す姿（2035〜2040年の将来像）

> **「住んでいる場所にかかわらず、かかりつけの総合診療と、必要なときの専門医療が受けられる恵那市」**

```
  【患者・地域】              【フロントエンド】               【バックエンド】
  重点地区の住民宅・公民館      市立恵那病院（総合診療）          藤田医科大学
       │                    （地域医療振興協会）               （専門医療・先進医療）
       │  ① 医療MaaS                 │                              │
       ├── 移動診療車 ─ 看護師 ──オンライン── 総合診療医 ──オンライン── 専門医
       │  （D to P with N）           │   ② 医師間の遠隔支援（D to D）│
       │                            │      必要時は三者同時          │
       │                            │      （D to P with D）         │
       │  ③ 服薬                     │                              │
       └── オンライン服薬指導 ── 薬局 ── 薬の配送                       │
                                    │                              │
                         国保上矢作病院・公立診療所（Step2以降で接続）
```

- 住民に最も近い入口（フロント）は、総合診療を担う **市立恵那病院**。
- 専門的な判断が必要なときは、恵那病院の医師が **藤田医科大学の専門医** にオンラインで相談・同席を依頼する（バック）。
- 移動・通院・薬の受け取りの負担を、**車両とオンラインで地域側に寄せる**。

## 5. 実証の内容

### 5-1. テーマ①：医療MaaS（移動診療車によるオンライン診療）

| 項目 | 内容（案） |
|---|---|
| 方式 | **D to P with N**：看護師が同乗した車両が患者宅・公民館等へ行き、車内で恵那病院の医師がオンライン診療 |
| 車両 | オンライン診療用の機器（通信、モニター、バイタル測定機器、心電計・エコー等）を搭載したワゴン車。購入・リース・既存の公用車改造を比較 【要見積】 |
| 運行 | **車両2台**で2ルートを巡回（予約制）。**北ルート：飯地・笠置**／**南ルート：山岡・串原**。例：各ルート週2〜3日から始め、利用状況で調整。運転手は委託または市の交通事業と連携 【要確認】 |
| 停車場所 | 各地区の公民館・集会所などを拠点に、必要に応じて自宅前まで（拠点は改正医療法の「オンライン診療受診施設」としての活用も検討） |
| 対象者 | 重点地区に住む慢性疾患で定期受診中の高齢者、通院困難者、退院後のフォローが必要な方 |
| 医師側 | 恵那病院の総合診療医。必要に応じて藤田医科大学の専門医が同時接続（D to P with D） |
| 検証すること | 利用者数・満足度、通院負担の削減、医師の移動時間削減、診療の質（対面と比べた安全性）、運行コスト、診療報酬での採算 |

### 5-2. テーマ②：医師間の遠隔支援（D to D）

| 項目 | 内容（案） |
|---|---|
| 方式 | 恵那病院の医師と藤田医科大学の専門医をオンラインで結び、症例相談・画像の共有・三者診療を行う |
| 対象診療科 | 検討中。次の3つの基準で選定し、**初年度は1〜2科から開始**することを提案。①恵那病院に常勤医がいない／少ない科、②重点地区の高齢者に多い疾患（例：心不全・不整脈、糖尿病・腎臓病、認知症・神経疾患、皮膚疾患）、③オンラインで情報共有しやすい科（画像・心電図・写真で判断できる、例：循環器・皮膚・画像診断） |
| 藤田医科大学への打診 | 12月中に、市・恵那病院（地域医療振興協会）同席で打診。協議事項：対象診療科、対応する専門医と時間帯、費用（謝金・委託料）、責任分担、個人情報の取扱い、学術評価への協力 |
| 運用 | 定期の症例カンファレンス（例：週1回）＋随時相談の仕組み。セキュアな映像・画像共有システムを導入 |
| 検証すること | 相談件数、遠方の病院への紹介・転院の回避件数、患者の移動負担削減、恵那病院医師の負担感・教育効果 |

### 5-3. テーマ③：オンライン服薬指導＋薬の配送

| 項目 | 内容（案） |
|---|---|
| 方式 | 移動診療車で処方 → 市内の薬局がオンラインで服薬指導 → 薬を自宅へ届ける |
| 配送手段（比較） | 下表のとおり。**初年度は (c) 薬局の配送を基本とし、(b) 貨客混載を試行**することを提案 |
| 参加薬局 | 検討中。市内薬局・薬剤師会に打診し、重点地区に近い薬局を中心に1〜2薬局から開始 |

| 配送手段 | 長所 | 短所 | 評価 |
|---|---|---|---|
| (a) 翌回の移動診療車が届ける | 追加費用が小さい | 受け取りまで数日かかる | 定期処方の補助的手段 |
| (b) 地域の交通・物流事業者との貨客混載 | 既存の便を活用、地域交通の維持にも寄与 | 調整が必要、便の時間に左右される | 試行 |
| (c) 薬局による配送（当日〜翌日） | 確実、服薬指導と一体で運用できる | 薬局の負担・コスト | **基本** |
| (d) ドローン | 山間部で速い | 機体・運航体制・天候、費用が大きい | 中長期の検討 |
| 検証すること | 処方から受け取りまでの時間、住民の負担削減、薬局の業務負担、配送コスト |

### 6-1. 推進協議会の設置（医療MaaS導入検討委員会の位置づけ）

医療MaaS導入検討委員会は未着手のため、**交付金事業の推進体制を兼ねた「（仮称）恵那市医療MaaS推進協議会」として、令和8年度中（12月〜1月）に設置**することを提案します。

- 構成：市（地域医療課・交通担当・デジタル担当・消防）、市立恵那病院／地域医療振興協会、藤田医科大学、恵那医師会、薬剤師会、重点地区の地域自治区・住民代表、地域包括支援センター、交通事業者、岐阜県（オブザーバー）
- 役割：実証計画の決定、KPIの設定と効果検証、住民への周知、実証後の本格導入の判断
- 交付金の申請では、**産学官の推進体制とKPIの検証体制**が評価されるため、設置の決定（要綱・委員名簿案）を申請時点で示せるようにする

### 6-2. 検討プロジェクト（協会×藤田医科大学の現場連携）【新設】

**名称（仮）**：恵那・藤田 医療連携検討プロジェクト

**目的**：市立恵那病院（地域医療振興協会）と藤田医科大学の**現場同士の意思疎通**を図る。組織間の協定や交付金の手続きだけでは決まらない、「誰に・いつ・どう相談するか」「どんな情報を・どの形で渡すか」を、実際に診療する医師・看護師・連携担当者どうしで合意し、顔の見える関係をつくる。

**推進協議会との関係**

| | 推進協議会（6-1） | 検討プロジェクト（6-2） |
|---|---|---|
| 位置づけ | 事業全体の意思決定・効果検証 | 推進協議会の下に置く**現場の作業部会** |
| 参加者 | 市、協会、大学、医師会、薬剤師会、地域代表、交通、県 等（代表者クラス） | 恵那病院と藤田医科大学の**現場担当者**＋市（事務局） |
| 頻度 | 年3〜4回 | 月1回の定例（オンライン中心）＋随時 |
| 決めること | 計画・予算・KPI・本格導入の判断 | 運用ルール・相談の流れ・システムの要件・教育 |

**メンバー（案）**

| 所属 | メンバー |
|---|---|
| 市立恵那病院（地域医療振興協会） | 総合診療医、移動診療車に同乗する看護師、地域医療連携室、医事・情報システム担当 |
| 藤田医科大学 | 対象診療科の医師、地域連携・遠隔医療の担当部門、事務担当 |
| 地域医療振興協会（本部） | 必要に応じて参加（他施設の知見の共有） |
| 恵那市 | 地域医療課（事務局）、デジタル担当 |
| オブザーバー | 薬剤師会・薬局（服薬・配送の検討時）、システム事業者（要件検討時） |

**主な活動（案）**

1. **キックオフ（対面）**：恵那病院・藤田医科大学の相互訪問。重点地区と移動診療車の運行ルートを大学の医師にも見てもらう
2. **月1回の定例会（オンライン）**：課題の共有と決定事項の確認。実証開始後は症例の振り返りも兼ねる
3. **ワーキンググループ**
   - 診療科・対象患者WG：対象診療科、紹介・相談の基準
   - 運用WG：相談の受付方法、対応時間、緊急時の対応、記録の残し方
   - 情報・システムWG：共有する情報（画像・心電図・検査値）、システムの要件、個人情報の取扱い
   - 教育WG：合同の症例検討会、看護師の研修、オンライン診療の研修
4. **試行と振り返り**：実証開始前に模擬診療・模擬相談を行い、運用を修正

**成果物**：連携運用マニュアル（相談の流れ・対応時間・緊急時対応）、対象診療科と対応体制の合意書、システム要件書、合同研修の記録、課題・改善リスト

**スケジュール**：令和8年度中（1月目途）に立ち上げ。交付決定前の活動経費は市の単独予算または各機関の持ち出しで対応し、令和9年度以降は交付金の対象経費（会議・旅費・研修費）とする方向で確認する。

## 7. 予算（規模感の仮置き）

前提：**初年度（令和9年度）8,000万円、3か年で1.5億〜2億円程度**（確定）。下表は3か年 **約1.75億円** で配分。【要見積】

| 費目 | 令和9年度 | 令和10年度 | 令和11年度 | 備考 |
|---|---:|---:|---:|---|
| 移動診療車 2台（車両・改造・医療機器・通信機器） | 2,400万 | – | – | 北・南ルート各1台。購入とリースを比較 |
| 遠隔医療連携基盤（オンライン診療、恵那病院⇔藤田医科大学の映像・画像共有、電子カルテ等との連携） | 2,000万 | 1,200万 | 800万 | 令和10年度に上矢作病院・公立診療所を接続 |
| 地区の受診拠点（公民館等の通信環境・機器） | 400万 | 200万 | – | オンライン診療受診施設としての活用も検討 |
| 運行（看護師・運転手 2台分、燃料・保険・保守） | 1,200万 | 2,400万 | 2,400万 | 令和9年度は秋開始のため半年分。診療報酬収入で一部相殺 |
| 服薬指導・薬の配送（薬局の機器、配送、貨客混載の試行） | 400万 | 400万 | 300万 | |
| **検討プロジェクト**（協会×大学の現場連携：相互訪問・会議・合同研修・専門医の対応謝金） | 800万 | 500万 | 400万 | 新設。専門医の遠隔対応の謝金・委託料を含む |
| 推進協議会・効果検証・住民周知・事業管理（PMO） | 800万 | 300万 | 600万 | 令和11年度は総合評価と横展開資料 |
| **合計** | **8,000万** | **5,000万** | **4,500万** | **3か年 1億7,500万** |

- 3か年の幅（1.5億〜2億円）の中で、**下限側（1.5億円）にする場合**は運行日数・システムの範囲で調整し、**上限側（2億円）にする場合**は対象地区の追加（上矢作・明智・岩村など）や受診拠点の増設に充てる。
- 交付金の補助率を1/2とした場合、**市の負担は3か年で約8,750万円（令和9年度は約4,000万円）**。地方財政措置の有無を確認する。
- 令和8年8月時点のデジタル実装型 TYPE A は国費上限1億円（事業費2億円）であり、令和9年度の8,000万円は上限内。
- 令和10年度以降に交付金の対象外となった場合でも続けられるよう、運行費は診療報酬と市単独予算で賄える水準を令和9年度の実証で検証する。

## 8. 交付金の活用方針（案）

| 候補 | 想定する使い方 | 論点 |
|---|---|---|
| **地域未来交付金 デジタル実装型 TYPE A（利用推進型）** | 令和9年度の初期導入（車両の機器・オンライン診療システム・D to Dシステム） | 補助率1/2・国費上限1億円（令和8年度の例）。**原則として単年度の実装事業**で、他地域で実績のあるモデルの導入が基本 → 医療MaaSは伊那市などの先行例があり適合しやすい 【要確認：令和9年度要件】 |
| **地域未来交付金 第2世代型（ソフト事業）** | 複数年度の運用・専門連携の拡大（Step1〜2） | 複数年度の計画を組める型。地方版総合戦略への位置づけとKPI設定が必要 【要確認】 |
| 地域医療介護総合確保基金（岐阜県） | 遠隔医療設備、在宅医療体制 | 県の計画への提案が必要。交付金との重複不可 |
| 診療報酬・市単独予算 | 実証後の運用費 | 自走のための財源 |

→ **基本戦略：初年度の導入を「デジタル実装型 TYPE A」、2年目以降の運用・拡大を「第2世代型」またはそれに相当する型で申請し、令和11年度以降は診療報酬と市予算で自走する**（型の併用・重複の可否は内閣府・県に要確認）。

## 9. KPI（案）

| 区分 | 指標 | 目標の考え方（数値は現状把握後に設定） |
|---|---|---|
| アウトプット | 移動診療車の運行日数・訪問件数 | 例：年間〇日・延べ〇件 |
| アウトカム（住民） | 利用者の通院にかかる時間・費用の削減 | 1人あたり〇分／〇円削減 |
| アウトカム（住民） | 利用者満足度・継続利用意向 | 80%以上 |
| アウトカム（医療） | 藤田医科大学との D to D 件数、遠方の病院への受診・転院の回避件数 | 年間〇件 |
| アウトカム（医療） | 医師の移動時間の削減（往診比較） | 〇時間／月 |
| アウトカム（服薬） | 処方から薬を受け取るまでの日数 | 〇日以内 |
| 連携（現場） | 検討プロジェクトの定例会・合同研修の開催数、恵那病院・藤田医科大学双方の担当者の連携に対する満足度 | 定例会 月1回、満足度80％以上 |
| 持続性 | 実証後の継続運行、診療報酬で賄える運営費の割合、他地区・他施設への横展開数 | 令和11年度に自走 |

## 10. 主なリスクと対応

| リスク | 対応 |
|---|---|
| 高齢者がオンライン診療に不安を感じる | 看護師同乗方式（D to P with N）、地域包括・民生委員と連携した説明会 |
| 医師・看護師の人員確保 | 地域医療振興協会のネットワーク、藤田医科大学の支援、運行日の集約 |
| 運営費が実証後に賄えない | 実証中に診療報酬での採算を検証し、運行ルート・頻度を最適化 |
| 法令・指針への適合（オンライン診療指針、改正医療法、個人情報、医療情報システムの安全管理） | 企画段階で厚労省指針に沿った運用手順書を作成、県の医療担当課へ事前相談 |
| 県境を越える連携の調整 | 三者協定、費用負担の明確化 |
| 交付金の要件・スケジュールの変更 | 内閣府・県への早期の事前相談、複数の財源候補を並行確保 |
