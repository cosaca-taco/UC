# 04 診療車・通信環境・電子カルテ・人件費の検討事項

作成日：2026-11-12 ／ 状態：検討用たたき台（**【要検討】** は検討プロジェクト・推進協議会で決める事項、**【要見積】** は業者見積が必要な事項）

前提（確定）：
- 移動診療車は **1台**。ただし **検査機器など診療車に必要な機器は要検討**
- **高速通信環境を整備**し、**電子カルテシステムの運用も視野**に入れる
- **実証実験に要する人件費を事業費に計上**する

---

## 1. 移動診療車（1台）

### 1-1. 運行の考え方

| 項目 | 内容（案） |
|---|---|
| 台数 | 1台 |
| 運行 | 曜日で北ルート（飯地・笠置）と南ルート（山岡・串原）を交互に巡回。例：週4日（南2日・北2日）から開始し、利用状況で調整 |
| 1日の流れ（例） | 恵那病院を出発 → 地区の拠点（公民館等）で診療 → 必要に応じて自宅前で診療 → 病院へ戻り、記録の確認・機器の清掃・充電 |
| 1日の診療件数 | 1件30分前後＋移動時間から、6〜8件程度を上限に試算 |

### 1-2. 車両の検討項目【要検討】

| 項目 | 検討内容 |
|---|---|
| 車種・サイズ | 山間部の狭い道に入れる大きさ（ワンボックス級）と、診察スペースの確保の両立 |
| 車内レイアウト | 診察用の座席またはベッド、看護師の作業スペース、モニターの配置、プライバシーの確保（カーテン・遮光） |
| 乗り降り | 車いす対応（リフト・スロープ）、手すり、踏み台 |
| 電源 | 走行用とは別のバッテリー、外部電源の接続口、機器の連続使用時間 |
| 空調・衛生 | 冷暖房、換気、感染対策（消毒・ゾーニング）、手洗い設備 |
| 取得方法 | 購入／リース／既存の公用車の改造を比較。先行自治体の仕様も参考にする |

### 1-3. 搭載する機器の候補【要検討】

検討プロジェクト（恵那病院・藤田医科大学の現場）で、**対象患者・対象診療科と、オンラインで医師が判断するために必要な情報**から逆算して決めます。

| 区分 | 機器の候補 | 主な用途 | 優先度（案） |
|---|---|---|---|
| オンライン診療 | 高画質カメラ・マイク・モニター、手元を映すカメラ | 医師と患者の対話、患部の観察 | **必須** |
| バイタル測定 | 血圧計、パルスオキシメーター、体温計、体重計 | 定期診療の基本データ | **必須** |
| 聴診 | デジタル聴診器（遠隔で医師が聴ける機器） | 心音・呼吸音の確認 | **必須** |
| 心電図 | 12誘導心電計（データ送信機能付き） | 心疾患の評価、藤田医科大学の専門医との共有 | 推奨（循環器を対象にする場合は必須） |
| 超音波 | ポータブル超音波診断装置（画像を送信できるもの） | 心臓・腹部・下肢などの評価 | 推奨 |
| 簡易検査（POCT） | 血糖・HbA1c、CRP、尿検査などの簡易測定機器 | 糖尿病の管理、炎症の評価 | 推奨 |
| 画像 | 皮膚・創傷の撮影用カメラ、耳・眼・口腔の観察カメラ | 皮膚疾患・褥瘡の評価 | 推奨（皮膚科を対象にする場合は必須） |
| 救急対応 | AED、酸素、救急セット | 体調急変時の対応 | **必須** |
| その他 | 採血用品、医薬品の保管（冷蔵庫）、感染対策用品 | 検体の持ち帰り、ワクチン等 | 【要検討】 |

**検討の視点**
- 対象診療科（藤田医科大学と協議中）によって、必要な機器が変わる（例：循環器なら心電計・超音波、皮膚科なら高画質カメラ）
- 機器のデータを **電子カルテや藤田医科大学へ送れるか**（データ連携機能の有無）
- 看護師が車内で無理なく操作できるか（研修が必要な機器の範囲）
- 薬機法上の医療機器の扱い、保守・校正の体制
- 診療報酬上、車内での検査が算定できるか

## 2. 高速通信環境

オンライン診療・画像の送信・電子カルテの利用は、**通信が途切れないこと**が前提です。山間部のため、重点地区での電波状況の実測から始めます。

| 場所 | 整備の内容（案） | 検討事項 |
|---|---|---|
| 移動診療車 | 複数の携帯電話会社の5G／4G回線をまとめて使う車載ルーター、**電波が弱い場所に備えた衛星通信（低軌道衛星）** | 重点4地区の停車予定地での通信速度の実測【要検討】 |
| 地区の受診拠点（公民館等） | 光回線とWi-Fi（車両が停車中に使える）、拠点での単独の受診にも使える端末 | 拠点の選定、既存の公共施設のネットワークの活用 |
| 恵那病院 | オンライン診療用の端末・回線の増強 | 院内ネットワークとの分離、セキュリティ |
| 恵那病院 ⇔ 藤田医科大学 | 医療情報をやりとりする**閉域網またはVPN**、画像など大容量データの送信 | 大学側のネットワーク方針、費用負担 |

**セキュリティ**：厚生労働省「医療情報システムの安全管理に関するガイドライン」と、事業者向けの関連ガイドラインに沿って設計します（通信の暗号化、端末の管理、アクセス権限、記録の保存）。

## 3. 電子カルテシステムの運用

**最終的な目標**：車内でも病院と同じように **恵那病院の電子カルテを見て、記録し、処方できる** 状態にし、藤田医科大学とも必要な情報を共有する。

| 段階 | 内容（案） | 時期 |
|---|---|---|
| 現状の確認 | 恵那病院・国保上矢作病院・公立診療所の電子カルテの導入状況（製品・更新時期・外部接続の可否）、地域医療振興協会の方針 | 令和8年度【要確認】 |
| 段階1 | 車内から恵那病院の電子カルテを**安全に参照・記録**（リモート接続）。マイナ保険証による資格確認、電子処方箋への対応 | 令和9年度 |
| 段階2 | 藤田医科大学との**画像・検査結果の共有**（専門医が判断に必要な情報を見られる） | 令和9〜10年度 |
| 段階3 | 上矢作病院・公立診療所との接続、国の**電子カルテ情報共有サービス**との連携 | 令和10年度〜 |

**検討事項**
- 電子カルテの製品・更新時期と、外部からの接続に必要な改修の範囲・費用【要見積】
- 指定管理者（地域医療振興協会）が管理するシステムに市の事業費で改修を加える場合の、**資産の帰属・費用負担**の整理
- 国の医療DX施策（電子カルテ情報共有サービス、標準型電子カルテ）との整合
- 個人情報の取扱いと、藤田医科大学との情報共有の同意の取り方

## 4. 実証実験の人件費

実証を担う人材の費用を、事業費に計上します。

| 職種 | 役割 | 配置の考え方（案） | 雇用・契約の形（案） |
|---|---|---|---|
| 医師（恵那病院） | 車両の患者のオンライン診療 | 運行日の診療時間分 | 恵那病院（協会）への委託 |
| 看護師 | 車両に同乗し、測定・診療補助・説明 | 運行日に1名＋交代要員 | 恵那病院（協会）への委託 |
| 運転手 | 車両の運転・機器の積み下ろし補助 | 運行日に1名 | 交通事業者等への委託 |
| 専門医（藤田医科大学） | 遠隔での相談・同席診療・症例検討会 | 相談件数・回数に応じて | 謝金または委託 |
| 薬剤師 | オンライン服薬指導 | 処方件数に応じて | 薬局への委託 |
| 実証コーディネーター | 予約の受付、住民への説明、関係機関との連絡、データの収集 | 1名（通年） | 会計年度任用職員または委託【要確認】 |
| 評価担当 | 効果検証の設計・分析 | 必要な期間 | 大学・調査機関への委託 |

**留意点**
- 交付金で人件費がどこまで対象になるか（委託先の人件費、自治体職員の人件費の扱い）を内閣府・県に確認する【要確認】
- 医師・看護師の人件費と**診療報酬の収入の関係**（二重に計上しない整理）を、協会と協議する
- 令和11年度以降に続けるため、人件費を診療報酬と市の予算でどこまで賄えるかを実証で検証する
